📝 Quick Note Application

A simple and user-friendly note-taking web application built using Python and Flask.

🚀 Features

- Create and save notes
- View saved notes
- Edit existing notes
- Delete notes
- Store notes using SQLite database
- Simple and responsive user interface

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

⚙️ Installation

1. Clone the repository:

git clone https://github.com/ganesh96183/quick-note-application.git

2. Open the project folder:

cd quick-note-application

3. Create a virtual environment:

python -m venv venv

4. Activate it on Windows:

venv\Scripts\activate

5. Install dependencies:

pip install -r requirements.txt

6. Run the application:

python app.py

7. Open your browser:

http://127.0.0.1:5000
